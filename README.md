# iplv-listings

A collection of
[IPL-V](https://en.wikipedia.org/wiki/Information_Processing_Language)
interpreters and programs extracted from the PDF originals.

## Interpreters

- [University of Oregon IBM 1620 IPL-V](./1620-oregon)

## Programs

- [EPAM - Elementary Perceiver and Memorizer](./EPAM)
- [LT - Logic Theorist](./LT)

For a way to run IPL-V code on modern machines, see
[Jeff Shrager's IPL-V](https://github.com/jeffshrager/IPL-V/) in
Common Lisp.
