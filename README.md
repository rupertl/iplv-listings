# iplv-listings

A collection of historical
[IPL-V](https://en.wikipedia.org/wiki/Information_Processing_Language)
programs and interpreters extracted to text from the PDF originals.

## Programs

- [EPAM - Elementary Perceiver and Memorizer](./EPAM)
- [LT - Logic Theorist](./LT)

## Interpreters

- [University of Oregon IBM 1620 IPL-V](./1620-oregon)
  - This is now running on Paul Kimpel's [retro-1620](https://github.com/pkimpel/retro-1620/tree/main/software/IPL-V).

## Links to other resources

- For a way to run IPL-V code on modern machines, see
[Jeff Shrager's IPL-V](https://github.com/jeffshrager/IPL-V/) in
Common Lisp.

- David Moews has created a Python interpreter that can run the IPL-V
  Logic Theorist, and has also got LT working on Rob Storey's IBM 7094
  emulator. See his repo
  [here](https://github.com/dmoews/ipl-v-logic-theorist).
